# verhoeff-core

Dígitos verificadores Verhoeff: pega todos os erros de um dígito e
transposições adjacentes. Zero dependências, Node >= 22.

Parte do laboratório open source da LOFRANO TECNOLOGIA. MIT.

```sh
npm test          # 4 testes, node:test, sem dependências
npm run demo
```

No máximo 64 dígitos. MIT — veja `LICENSE`.
